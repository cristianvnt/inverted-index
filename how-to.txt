# Inverted Index - Hadoop Setup

## Prerequisites
- Docker Desktop installed with WSL2 backend
- Ubuntu WSL2 distro with Docker integration enabled
- VS Code with WSL extension (optional)

## First time setup

### 1. Clone the Hadoop repo
```bash
git clone <repo-url> hadoop-docker
cd hadoop-docker
```

### 2. Build the base image
```bash
cd base
docker build -t asergiu/ubb:hadoop-base .
cd ..
```

### 3. Build all images
```bash
docker compose build
```

### 4. Start the cluster
```bash
docker compose up -d
```

Wait ~30 seconds, then verify at http://localhost:9870
- Click Datanodes tab — should show 3 live nodes

### 5. Setup the inverted index
```bash
cd ~/inverted-index
./setup.sh
```

## Running the job
```bash
./run.sh
```

## Stopping the cluster
```bash
cd ~/hadoop-docker
docker compose down
```

## Restarting the cluster
```bash
docker compose up -d
# wait for safemode to clear (~30 seconds)
./setup.sh  # re-copy files since containers are fresh
./run.sh
```
