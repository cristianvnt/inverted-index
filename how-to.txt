# Inverted Index - Hadoop Setup

## Prerequisites
- Docker Desktop installed with WSL2 backend
- Ubuntu WSL2 distro with Docker integration enabled
- VS Code with WSL extension (optional)

## First time setup

### 1. Clone both repos
```bash
# Hadoop cluster (modified from original asergiu/hadoop-docker)
git clone https://github.com/asergiu/hadoop-docker.git ~/hadoop-docker

# Inverted index code
git clone https://github.com/cristianvnt/inverted-index ~/inverted-index
```

### 2. Build the base image
```bash
cd ~/hadoop-docker/base
docker build -t asergiu/ubb:hadoop-base .
cd ..
```

### 3. Build all images
```bash
cd ~/hadoop-docker
docker compose build
```

### 4. Start the cluster
```bash
docker compose up -d
```
Wait ~30 seconds, then verify at http://localhost:9870
- Click Datanodes tab — should show 3 live nodes

### 5. Add books
Put plain text books (.txt) from https://gutenberg.org into `~/inverted-index/books/`. 
One sample book (pg43.txt) is already included.

### 6. Setup the inverted index
```bash
cd ~/inverted-index
./setup.sh
```

## Running the job
```bash
cd ~/inverted-index
./run.sh
```

## Stopping the cluster
```bash
cd ~/hadoop-docker
docker compose down
```

## Restarting after shutdown
```bash
cd ~/hadoop-docker
docker compose up -d
cd ~/inverted-index
./setup.sh
./run.sh
```

## Changes made to the original hadoop-docker repo
- `base/Dockerfile` — fixed Hadoop download URL from `/stable/` to version-specific path
- `base/Dockerfile` — added `python3` to apt install
- `docker-compose.yml` — uncommented datanode2 and datanode3
- `docker-compose.yml` — added port 8088 to resourcemanager
- `docker-compose.yml` — fixed nodemanager SERVICE_PRECONDITION (removed nonexistent `datanode:9864`)
- `hadoop.env` — fixed HADOOP_MAPRED_HOME from 3.3.5 to 3.4.0
- `hadoop.env` — reduced map/reduce memory to 2048MB to fit single-machine Docker setup
